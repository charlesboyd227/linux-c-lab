# Linux, Shell, and C Lab

## Overview

This repository contains my work for the Ubuntu Linux, shell scripting, and C programming lab. It includes command-line exercises, shell scripts, C programs, testing, debugging, and an integration project.

## Structure

- `command-line-easy/` - Linux command-line exercises and log files
- `shell-scripts/` - Shell scripts for automation and file management
- `c-programs/` - C programs and compiled program exercises

## Testing and Running

### Command Line

I practiced commands including `pwd`, `ls`, `cd`, `mkdir`, `touch`, `cp`, `mv`, `rm`, `cat`, `grep`, `find`, `chmod`, `whoami`, `uname`, `ps`, `top`, `curl`, `tree`, and aliases.

### Shell Scripts

I created and tested shell scripts for:

- User input and displaying the date
- Conditionals
- Loops
- Functions
- Checking whether files exist
- Command-line arguments
- Error handling
- Backups
- Counting files by type
